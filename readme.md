# JSONHUD

> This project is still heavily work in progress and not all HUD properties/functions are currently supported.

## Requirements

Place these libraries inside your `scripts\` directory before using this module:

### Strings Library
https://github.com/Yallamaztar/strings

Required functions:
- `printlnf()`
- `len()`

### JSON Library
https://github.com/Yallamaztar/JSON

Required functions:
- `read()`
- `json_object()`
- `object_keys()`
- `object_get()`
- `object_add()`
- `json_array()`
- `array_add()`
