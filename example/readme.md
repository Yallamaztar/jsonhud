# Example Usage

Simple example of using the jsonhud script to create a `ServerFontString` element.

## Installation

**After installing** `hud.gsc` and **its dependencies** into your `scripts\` directory, **move `test.gsc`** into your `scripts\` directory as well.


### Move the `.json` file from:

```text
raw\scriptdata\hud.json
```

to:

```text
Plutonium\storage\t6\raw\scriptdata\
```
